# Roadmap

Direction for `my-skill`. Nothing here is scheduled or guaranteed — ideas graduate
into changelog entries only when they earn their place. Suggestions welcome via PR
(see [`CONTRIBUTING.md`](../CONTRIBUTING.md)).

## Next

- Vault auto-sync: thesis/job skills write notes to `01-Thesis\` / `admin_api\` and log the sync
- `/my-skill:weekly`: git logs + vault tasks → standup draft, thesis progress, next-week priorities
- Run the `evals/transitions.json` scenarios live and record where `workflow-adapter` misses
- Log real-usage lessons in `lessons-learned.md` for 1-2 weeks before changing skills
- Run the `evals/triggers.json` prompts through a live session and record misses
- Fill the `[add ...]` placeholders in `workflow-profile.md` (team conventions, deploy environment)
- Improve `continuous-improvement` workflow (richer retros, better diff proposals)
- Add more practical examples (`examples/`)
- Improve `skill-health-check` (sharper overlap detection, freshness signals)
- Improve `workflow-profile` customization (more/better-typed profile sections)

## Later

- Add optional commands for common workflows
- Add project-specific skill packs
- Improve contribution workflow (templates, generators)
