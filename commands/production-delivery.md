# production-delivery

1. Read `skills/production-delivery/SKILL.md` and follow it exactly.
2. Use `$ARGUMENTS` as the deliverable and its state. If empty, ask: "What should be shipped, by when, and where does it stand?"
3. Build the phase map first; delegate each phase's craft to its owner skill; record every gate decision (Design/Plan/Ship pauses for user go/no-go — never chain Ship).
4. Keep a delivery status block current; close with a retro and route lessons to `continuous-improvement`.
